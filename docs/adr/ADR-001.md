# ADR-001: Monólito Spring MVC com renderização server-side

## Status

Aceita — registro retrospectivo do estado atual.

## Contexto confirmado

O projeto possui um único `pom.xml`, uma classe `@SpringBootApplication`,
controllers MVC, templates Thymeleaf e um único JAR/Dockerfile. Não há serviços
independentes nem frontend separado.

## Decisão observada

Entregar administração e urna em um monólito Spring Boot em camadas, com HTML
renderizado no servidor.

## Motivações e alternativas

Motivação original, escala, equipe, opções consideradas e critérios de escolha:
**Esta informação não pôde ser confirmada no estado atual do projeto.**

## Consequências observáveis

### Positivas

- um artefato para compilar e implantar;
- sessão, segurança, MVC e persistência no mesmo processo;
- fluxo direto entre controller, service e repository.

### Negativas

- componentes escalam e são implantados juntos;
- templates e Java exigem novo empacotamento;
- falha no processo afeta urna e administração.

## Gatilhos para revisão

Escala independente comprovada, equipes autônomas ou requisitos de
disponibilidade que o processo único não atenda. Esses gatilhos são orientações
de manutenção, não requisitos atuais confirmados.
